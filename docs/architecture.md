# Как читать код

1. `src/main.py` читает настройки, создаёт Bot и Dispatcher, подключает два обработчика и запускает polling.
2. `src/handlers/menu.py` содержит функции команд и нажатий. Название функции описывает действие: `start`, `select_discipline`, `open_match`, `show_bonus`.
3. `src/keyboards/menu.py` собирает кнопки. Каждая кнопка передаёт короткую строку вроде `sport:cs2` или `match:navi-faze`.
4. `src/content.py` содержит тексты и примеры из Figma. Их можно менять без чтения обработчиков.
5. `src/services/users.py` хранит только факт первого запуска и выбранную дисциплину в JSON. Замена файла атомарная; хранилище рассчитано на один процесс.
6. `src/handlers/donate.py` отдельно обрабатывает Stars: счёт → pre-checkout → успешная оплата → `Ок, принят`.

Основной путь: `/start` → выбор игры → список → разбор → пауза 3 секунды → бонус.

HTML-разметка сообщений включена в настройках Bot. Картинка бонуса загружается из `assets/bonus.png`; интерфейс самого Telegram, фон чата и системные иконки не воспроизводятся в коде.

Реальных AI-ответов и внешних запросов к статистике пока нет. Уведомления представлены текстами и командой `/preview`, без автоматической рассылки. Новые интеграции следует добавлять по мере появления источников данных, не создавая заранее дополнительные слои.
