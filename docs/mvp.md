# Реализация сценария Figma

Источник: [user flow](https://www.figma.com/design/BHxPEFEcG5SX6PH8jHf89P/?node-id=0-1). Содержимое прочитано 27 сентября 2026 года; использованы тексты, кнопки и скриншоты актуальных экранов.

| Экран Figma | Реализация |
| --- | --- |
| 1196:210 — первый /start | Приветствие, CS-2 / Dota 2 |
| 1201:506 — повторный /start | Короткий выбор дисциплины |
| 1001:473 — список матчей | Четыре примера CS-2, назад |
| 1001:105 — разбор | NAVI — FaZe, текст из макета |
| 1001:252 — бонус | Оригинальная картинка, шесть кнопок, реакция 🔥, задержка 3 секунды после разбора |
| 1001:178 — /info | Текст и переход к матчам |
| 1199:302 — дневной пуш | `/preview daily` |
| 1200:382 — фаворит дня | `/preview favorite` |
| 1001:399 — за 30 минут | `/preview reminder` |
| 1001:325 — после матча | `/preview result` |

Левые экраны под пометкой «БРАК» не использованы. Плейсхолдеры `(pe)` не перенесены: ID пользовательских эмодзи не предоставлены. Текст, оформление Telegram и кнопки отображаются средствами самого Telegram.

В меню четыре команды из макета: `/start`, `/info`, `/askbetty`, `/bonus`. Для `/askbetty` в Figma нет экрана и логики; сейчас команда открывает примеры разборов с пояснением, что AI ещё не подключён.

Данные из макета помечены как демо. Для Dota 2 нет матчей; разбор заполнен только для NAVI — FaZe. У предложений нет реальных ссылок. Числа на бонусной картинке и коэффициенты — примеры оформления, а не подтверждённые предложения.

Чтобы перейти к реальным прогнозам, нужны источник матчей/статистики, AI-провайдер, партнёрские ссылки и данные о времени начала/результатах матчей. Автоматические уведомления, генерация прогнозов и пагинация большого списка ещё не реализованы.

Команда доната сохранена как отдельная внутренняя функция, без поддержки и отдельного хранения платежей, согласно указанию пользователя.
