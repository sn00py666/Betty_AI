# Сценарий Figma и реальные данные

Источник: [user flow](https://www.figma.com/design/BHxPEFEcG5SX6PH8jHf89P/?node-id=0-1), прочитан 4 октября 2026.

| Экран | Реализация |
| --- | --- |
| Первое / повторное приветствие | Приветствие или короткий выбор CS2 / Dota 2 |
| Матчи | Свежие снимки букмекеров, пагинация, обновление |
| Разбор | Рыночная вероятность, AI-комментарий по котировкам, лучшие цены |
| Бонусный экран через 3 секунды | Обычные ссылки: реальных партнёрских предложений пока нет |
| /info | Фактические возможности и ограничения |
| Дневная подборка / фаворит | По подписке через /notifications, 12:00 / 18:00 МСК |
| Напоминание | За 30 минут по кнопке в карточке; только с подтверждённым временем |
| Итог матча | Не подключён: нужен проверяемый источник результатов |

Нативный интерфейс Telegram. Данные макета, картинка с обещанием 80 000 ₽, фиктивные результаты удалены
из пользовательского сценария. Картинка сохранена в assets как исходный материал.

AI не получает историю встреч и не оценивает игровую форму. До подключения статистики это объяснение
рынка, а не независимый прогноз. Счёт серии модель не придумывает. `/askbetty` открывает выбор матча.
