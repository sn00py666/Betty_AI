Для завершения нужны источник раундовых результатов, согласованное правило расчёта и заполнение показателя для обеих команд; примерные числа из сообщения Динара не являются данными матча.

Требуются источник данных по картам и определение «активной карты»; после этого показатель должен участвовать в прогнозе и появляться в карточке при наличии данных.
